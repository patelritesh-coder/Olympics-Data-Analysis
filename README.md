🏅 Olympic Medals Analysis Dashboard (2000–2024)
This Power BI project offers an interactive analysis of Olympic medal performance across countries from 2000 to 2020, complemented by a dedicated dashboard for the 2024 Olympics. The dashboard highlights top-performing countries by medal type, total medals, and country-wise trends, providing valuable insights into Olympic performance patterns.

📊 Dashboards Included
🥇 1. Olympic Medals Analysis (2000–2020)
Displays medal counts across six Olympic events (2000–2020)

Includes:
Total medals by country and year
Top 10 countries by Gold, Silver, and Bronze medals
Medal trends across time
Interactive filters (Year, Country)

🥈 2. Olympics 2024 Dashboard
Captures the medal performance of countries in the 2024 Olympics
Includes:
Total medals and participant countries
Top 5 countries by Gold, Silver, Bronze, and Total medals
Geographical view of participating countries
India's performance in 2024

🛠 Tools Used
Power BI Desktop
Microsoft Excel (for data cleaning)
DAX (for calculations and measures)

📂 Dataset Source
Datasets are compiled from public Olympic records and sports databases.

💡 Key Insights
The USA has consistently dominated Olympic medals from 2000 to 2024.
In 2024, China and the USA tied in Gold medals, but the USA leads in Silver and Bronze.
India's performance improved in 2024, with a total of 6 medals.
Visual analysis of country-wise performance trends over two decades.

🚀 How to Use
Open the .pbix file using Power BI Desktop.
Use filters on the right panel (Year, Country) to explore medal trends.
Hover over charts to view exact medal counts and breakdowns.

⚠️ Limitations
2024 data is based on assumed or provisional data (for demo purposes).
Some medal counts may not reflect real-time updates.
